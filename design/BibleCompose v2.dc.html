2Fresh start — calm editorial, layout rethought around the page

Type: Newsreader for titles and the proof page, Source Sans 3 for the interface, IBM Plex Mono only for codes and file sources. Warm paper neutrals, one quiet ink-blue for the primary action and selection, 6–8px radii, hairlines instead of rules. Comfortable density (40px rows). The layout is rethought: the page itself is the centre of the app — a live proof spread — with the settings for one section in an inspector on the right and a table-of-contents rail on the left. Clicking any element on the page (a header, a verse number, a margin) opens its setting, and Find a setting (Ctrl K) jumps by name. Screens that have no page to show (Books, Template, Build) use the same three panes with the canvas swapped for a table or gallery.
